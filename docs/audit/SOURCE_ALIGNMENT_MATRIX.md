## A3. Declarative Attention (DA) vs arXiv 2609.02737 and FMInference-style upstream

Original protocol (S3 §2, §2.2–2.3; S4 `docs/DESIGN.md` §2–3): the model emits `<global>`, `<focus magic_chunks="…">` and `<local>` modes; the FSM switches on recognized tags and applies the new mask on the **next** forward. GLOBAL = full context. FOCUS = sink + selected segments + open tail. LOCAL = sink + open tail (no context segments). Sink = first 16 tokens. Segment IDs are 1-based, at most 3 per focus. The mask applies only to global-attention layers. The question and response so far stay attended in every mode.
